# mjn propiedades — propuestas de sitio web

Dos propuestas estáticas publicadas en GitHub Pages para recoger opiniones.

- `propuesta-a/`: copia de `mjnpropiedades-codex` (HTML + JS sin dependencias)
- `propuesta-b/`: copia de `mjnpropiedades-claude/site` (HTML estático generado)

Diferencias con los originales: se agregó `noindex` a todas las páginas, se quitaron `robots.txt`/`sitemap.xml`, en B se reemplazó el WhatsApp de ejemplo por `56900000000` y en A se omitieron 6 fichas huérfanas que ya no estaban en `data.js`.
